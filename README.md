# Caso práctico: integración de criptografía

Aplicación de documentos confidenciales en PHP y PostgreSQL con cifrado AES-256-GCM y firma RSA/SHA-256 mediante OpenSSL.

Para configurar la base, generar las claves, ejecutar el proyecto y realizar la demostración, consulta [GUIA_CRIPTOGRAFIA.md](GUIA_CRIPTOGRAFIA.md).

El proyecto se basa en el trabajo del equipo en [SC-CP2-Confidencialidad](https://github.com/edgaraltunar06-eng/SC-CP2-Confidencialidad). Las contraseñas, claves y datos de pruebas deben mantenerse fuera del repositorio. Se han excluido las semillas y respaldos antiguos que contienen datos personales o de procedencia no confirmada.

Las pruebas criptográficas pasaron; la ejecución completa con PostgreSQL queda pendiente de comprobar en el entorno del equipo.
